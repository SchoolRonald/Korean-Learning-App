Basics and Introduction

New to Korean? Start here: turn on Korean typing, meet the alphabet (한글, Hangul), then try the letter quiz.

1. Turn on Korean typing

Windows: Settings → Time & language → Language & region → Add a language → Korean. Switch between English and Korean with Win + Space.

Mac: System Settings → Keyboard → Input Sources → Edit → + → Korean → 2-Set Korean. Switch with Ctrl + Space.

Letters stack into syllable blocks as you type. Type the letters in order and the keyboard builds the block for you: ㅎ + ㅏ + ㄴ = 한, typed as G K S.

2. The alphabet

Click a letter to see which key types it. "Strong" consonants are said with a puff of air.

3. The keyboard

Korean 2-set (두벌식) layout. The small letter at the top right is what Shift gives.
